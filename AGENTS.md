# PPI repository instructions

Milestone instructions govern scope; later features require their own task brief. Stack: npm workspaces, React/Vite, Express, TypeScript, Docker PostgreSQL, Prisma 6 groundwork. Docker PostgreSQL is the only supported local PPI database path. Verify with `npm run typecheck`, `npm run lint`, `npm test`, `npm run build`, and optional `npm run test:e2e`. Preserve local work and do not touch sibling projects, unrelated databases, or Docker volumes. Treat ignored local env files as user-owned: never overwrite, regenerate, print, or commit them. Do not print or commit secrets, connection strings, raw provider records, or Places content. Provider data must be represented truthfully: missing or nearby schools are not assigned schools; listing asks are not recorded sales. Places results remain transient under Esri terms. Live smoke requires explicit flag and environment gate, with no retries or fallback.

Post-freeze school scope: the product displays Nearby Schools (schools around the subject), not assigned schools. Zillapi nearby metadata may be displayed with explicit third-party provenance and an attendance-eligibility disclaimer. Use only returned metadata; do not invent school coordinates, attendance assignments, boundaries, or nearest-school guarantees. Preserve SCHOOL_ASSIGNMENT_PROVIDER as the legacy configuration name so existing ignored env files remain untouched.
